Far Horizons ISGC 2026-27. Experiments with a Raspberry Pi 5 and High Quality Camera (Sony IMX477) module.

Here is a description of the files in this repository:
- `docs`: more information on this repository and how it is used
  - `OPERATION.md`: how to use the star_tracker.py on the hardware
  - `STATUS.md`: general updates, planned features, known issues
- `logs`: folder to store diagnostics
- `photos`: folder to store images
- `tools`: Python scripts for quick tasks or modular development
  - `array-capture.py`
  - `cam-config.py`
  - `diagnostic.py`
  - `hello-world.py` 
- `star_tracker.py`: current startup program
